# Cheesy Cheese Website

**Date:** February 2024

**Purpose:** A mock website for a fictional charcuterie board business, designed to simulate a small business's online presence.

**Technologies:** HTML, CSS, JavaScript

**Features:**

* Multi-page website with a navigation bar
* JavaScript image slideshow and hover animations
* Order form with user input validation
* Clickable logo that redirects to the homepage
* Deployed to a live web server for public access

**Instructions:** Clone the repository and open `index.html` in your web browser.
